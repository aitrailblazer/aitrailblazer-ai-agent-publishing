User Flow With A Known TripCode

  • User enters a known TripCode such as HUT-RIVER-001.
  • The system resolves the TripCode into the linked article, claims, and River edges.
  • The agent produces a source-grounded answer and shows the connected memory objects.
  • The user asks a follow-up such as What should I monitor next?.
  • The system uses the prior session memory to continue without requiring the user to repeat the TripCode.
