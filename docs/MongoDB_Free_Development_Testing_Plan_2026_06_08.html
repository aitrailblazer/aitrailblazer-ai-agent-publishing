MongoDB Free Development Testing Plan

Generated 2026-06-08 for aitrailblazer-ai-agent-publishing. This artifact summarizes official MongoDB free development paths and maps them to the TripCode/River publication-memory product.

Cloud Demo: Atlas Free Cluster

Use a MongoDB Atlas Free cluster for the hackathon demo database. It is free forever, suitable for learning and small proof-of-concept apps, and includes 512 MB storage with shared RAM and shared vCPU.

Local Dev: Local MongoDB

Use a local MongoDB deployment for repeatable development and tests that should not depend on external accounts, IP allowlists, or cloud availability.

Agent Dev: MongoDB MCP

Use the official MongoDB MCP Server in read-only mode for schema inspection, sample queries, and agent-assisted development against either Atlas or a local MongoDB deployment.

Gemini CLI Extension

The MongoDB Gemini CLI extension is free to use and fits the permitted Google tooling lane. It requires a Google account and should be checked against current Gemini CLI requirements before final setup.

Unified Billing

For any Atlas usage beyond free-tier testing, subscribe to MongoDB through Google Cloud Marketplace so Atlas usage draws down hackathon Google Cloud credits cleanly instead of creating a separate MongoDB billing relationship.

Recommended Free Architecture

Keep the default app deterministic and free. Add MongoDB as an optional persistence adapter behind environment variables. Use Atlas Free for judge-visible cloud demos and local MongoDB for CI/integration tests.

Billing And Credits

Use Atlas Free for zero-cost development and smoke testing. If the demo needs paid Atlas capacity or marketplace-managed billing, subscribe to MongoDB through Google Cloud Marketplace so usage is tied to Google Cloud unified billing and can draw down the hackathon credits. The MongoDB Gemini CLI extension is free to use, subject to current Gemini CLI requirements and Google account setup.

Free-Tier Guardrails

Atlas Free clusters are intentionally constrained: one Free cluster per Atlas project, a subset of supported regions, fixed storage and memory, automatic maintenance, no configurable backup, no private endpoints, no network peering, and no dedicated workload-isolation/search nodes. For this project, that is acceptable because the free cluster should hold demo-sized article metadata, TripCodes, River edges, and a small embedding sample.

Testing Plan

Unit Tests

Use interfaces and in-memory fakes. No MongoDB connection string required. These tests stay in the normal make check gate.

Local Integration

Run MongoDB locally, seed a tiny DeltaSignal fixture, and run tests only when MONGODB_URI is set.

Atlas Smoke

Use Atlas Free only for manual or scheduled smoke tests. Keep dataset size under 512 MB and back up with mongodump if needed.

MCP Inspection

Configure MongoDB MCP read-only for agent/schema inspection. Use write-capable MCP only in a disposable demo database.
