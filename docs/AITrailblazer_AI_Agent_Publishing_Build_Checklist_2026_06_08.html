MongoDB Schema Checklist

articles
Canonical publication records with article_id, title, date, summary, source_label, source_url, tripcode, key_claims, river_id, role, searchable_text, and provenance.
tripcodes
Stable handles mapped to three article IDs, claim IDs, and one target River ID.
claims
Extracted claim text, article references, evidence type, confidence label, status, and River ID.
river_edges
Relationships across articles and claims. Valid labels: continuation, update, contradiction, theme_link, expands, monitors.
reader_sessions
User questions, resolved TripCode, retrieved articles, retrieved claims, retrieved edges, last answer summary, and next actions.
agent_runs
Tool calls, MCP context summary, Gemini model, prompt metadata, output summary, latency, status, and timestamp.

Core Agent Flow Checklist

Flow 1

TripCode Resolution

User enters Resolve HUT-RIVER-001. App queries TripCode memory, fetches three linked articles, claims, River edges, MCP context proof, Gemini synthesis, reader session, and agent run record.

Flow 2

River Traversal

User asks What changed across this River?. App compares prior, anchor, and follow-up articles, labels relationships, generates a concise comparison, and saves session memory.

Flow 3

Second-Turn Memory

User asks What should I monitor next?. App reads prior session, avoids TripCode re-entry, uses River state, generates monitor-next prompts, and writes follow-up memory.
